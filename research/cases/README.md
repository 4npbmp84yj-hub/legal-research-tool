# Case Research

This directory contains individual research notes on Indian judicial decisions.

Each case note should record:

- Case name
- Court and bench
- Citation
- Date of judgment
- Material facts
- Issues
- Arguments
- Decision
- Ratio decidendi
- Important observations
- Statutes and constitutional provisions considered
- Cases relied upon
- Cases distinguished or overruled
- Subsequent treatment
- Sources
